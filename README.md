# Symferium

A standalone local AI runtime for Apple Silicon. It downloads, loads and unloads many models at once (chat, vision, embeddings, rerankers, speech), serves each one on its own localhost port with an OpenAI-compatible API, and is managed from a thin browser UI and a local API that agents can use.

Status: planning. Start with `docs/BRIEF.md`, then `docs/SPEC.md`.
